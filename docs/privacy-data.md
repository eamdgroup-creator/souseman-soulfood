# Personal data on this site [4.2]

**What the site collects: nothing.** It is static HTML. There are no forms, accounts, cookies set by the site, or analytics (as of the 2026-11-03 preview).

Third parties a visitor may interact with:

| Where | What happens | Whose policy applies |
|---|---|---|
| Google Maps embed (`#location`) | Google may set cookies or log the visit when the map loads | Google |
| Order online links | Ordering happens on DoorDash or Uber Eats | DoorDash, Uber |
| Facebook and Instagram links | Opens their sites | Meta |
| Hosting (Render) | Standard server access logs (IP address, user agent) | Render |

The site shows **public Google reviews**, quoted verbatim with reviewer first name and last initial only, plus a link back to Google.

**If this changes:** before adding a contact form, newsletter or analytics, update this file and `/privacy/`. Document the fields collected, the purpose, where the data goes, how long it's kept, and how to ask for deletion.
